# กล้องถ่ายภาพติดวิญญาณ (Ghost Camera) — Design

วันที่: 2026-11-10 · เกี่ยวกับ: `h-ticket-frontend` (หลัก) + `H-Ticket-Backend` (ตัวนับ)

## ทำไม

ส่วน "ลองถ่ายรูปบ้านนี้ดู" บนหน้าแรกตอนนี้เป็นกล้องจำลอง: กดชัตเตอร์แล้วได้รูปบ้าน mock ที่บางทีมีเงาผีวาดด้วยโค้ด
เจ้าของงานอยากให้มันเป็นของเล่นจริงที่คนอยากเล่นและเอาไปแชร์: **เปิดกล้องจริง ถ่ายตัวเอง แล้วได้รูปที่มีผีติดอยู่ด้านหลังแบบภาพถ่ายติดวิญญาณ ดาวน์โหลดได้**
เป็นตัวโปรโมตงานบ้านผีสิง (Lanna Festival · เสาร์ 14 พ.ย. 2569 · ลานดาว)

## เป้าหมาย

1. คนเปิดหน้าแรก (ส่วนใหญ่มือถือ) กดเปิดกล้อง → เห็นภาพสด → กดชัตเตอร์ → หน้ารอ "กำลังล้างฟิล์ม…" → ได้รูปที่มีผี
2. **สิ่งที่เจ้าของงานเน้นที่สุด: ผีต้องอยู่ "ด้านหลัง" คนได้ และต้องดูเนียน** (ผีถูกไหล่/หัวบังจริง สี แสง ความชัดกลืนกับรูป)
3. มีหลายแบบ: ผีติดด้านหลังคน และผีโผล่จากมุม/ขอบจอ
4. ดาวน์โหลดรูปผลลัพธ์ได้ และถ่ายใหม่ได้
5. นับว่ามีการถ่ายไปกี่ครั้ง แอดมินเห็นตัวเลข

## ไม่ทำ (non-goals)

- ไม่ส่งรูปถ่ายไปเซิร์ฟเวอร์ ไม่เก็บรูป ไม่มีแกลเลอรี/ขึ้นจอที่งาน
- ไม่ใช้ AI สร้างภาพต่อรูป (ไม่ใช้ Stable Diffusion/บริการภายนอกตอนรันจริง) — AI ใช้แค่ครั้งเดียวตอนสร้างไฟล์ผี
- ไม่ทำวิดีโอ/ฟิลเตอร์สด (ผีไม่ต้องขึ้นในภาพสดก่อนกดถ่าย)
- ไม่นับคนแบบระบุตัวตน (นับเป็น "จำนวนครั้งที่ถ่าย")

## ห้ามเกิด (anti-goals)

- ผีดูเหมือนสติกเกอร์แปะทับหน้าคน / ขอบแข็ง / ลอยอยู่หน้าคน — ถือว่าล้มเหลวแม้ทำงานได้
- ผีบังหน้าคนถ่าย
- รูปหน้านักศึกษาหลุดออกจากเครื่อง
- ใช้หน้าผีจากหนังจริง (ลิขสิทธิ์) — รูปใน `~/Downloads/Haunted pic` เป็นภาพจากหนัง ใช้เป็น**แบบอ้างอิงลุคเท่านั้น**

## สิ่งที่ตกลงกันแล้ว (จากเจ้าของงาน)

- **ประมวลผลในเบราว์เซอร์ของคนถ่ายทั้งหมด** (เลือกแบบที่ 1 จาก 3 แบบ) — เดิมเจ้าของงานคิดว่าต้องทำที่เซิร์ฟเวอร์ แต่ไม่มีเหตุผลอื่นนอกจากนั้น
- เซิร์ฟเวอร์รับแค่ "+1 ครั้ง" สำหรับตัวนับ
- ผีสร้างด้วย AI **ครั้งเดียว** เป็นไฟล์ แล้วสุ่มใช้ · ลุคอิงจากรูปอ้างอิง: ผีผมยาวหน้าเละตาขาว, ผีผมยาวปิดหน้า, ผีหน้าขาวสวมชฎา, ผีชฎาหน้าเน่า (+ มือซีดแตะไหล่) · ประมาณ 4–6 ตัว
- ผีเป็นแบบ **"จางสว่าง" แบบภาพติดวิญญาณ** ไม่ใช่ผีชัดเหมือนคนจริงยืนอยู่ (ยืนยันแล้ว)
- ผีสร้างบน**พื้นดำสนิท** แล้วผสมแบบแสง (screen/lighten-like) ไม่ต้องตัดขอบ → ไม่มีขอบแข็ง (ยืนยันแล้ว)
- มีหน้ารอ "กำลังล้างฟิล์ม…" เพื่อความลุ้น

## วิธีทำ (ระดับที่ตกลงแล้ว)

### ขั้นตอนผู้ใช้

1. ส่วนกล้องบนหน้าแรก (แทน `FlashCamera` เดิม) แสดงปุ่ม "เปิดกล้อง"
2. ขอสิทธิ์ `getUserMedia` · ค่าเริ่มต้นกล้องหน้า มีปุ่มสลับกล้องหลัง
3. ภาพสดในกรอบ 3:4 → กดชัตเตอร์ → แฟลชวาบ (ใช้กติกาแฟลชเดิม: ไม่ถี่กว่า 1 ครั้ง/1.5 วิ, เคารพ reduced motion) → หยุดกล้อง
4. หน้ารอ "กำลังล้างฟิล์ม…" ขั้นต่ำ ~2 วินาที (ถ้าประมวลผลนานกว่าก็รอจนเสร็จ)
5. แสดงรูปผลลัพธ์ + ปุ่ม **ดาวน์โหลด** (JPEG) + **ถ่ายใหม่**
6. ส่ง +1 ไปเซิร์ฟเวอร์ (ยิงแล้วลืม ไม่ทำให้ UX รอ/พังถ้าล้มเหลว)

### ถ้าใช้กล้องไม่ได้

ปฏิเสธสิทธิ์ / ไม่มีกล้อง / ไม่ใช่ https / เบราว์เซอร์ไม่รองรับ → แสดงข้อความสั้น ๆ แล้วใช้**กล้องจำลองเดิม** (รูปบ้าน mock + ผีวาดด้วยโค้ด) แทน — ห้ามเป็นหน้าว่าง
หมายเหตุ: `getUserMedia` ใช้ได้เฉพาะ https หรือ localhost

### การหาตัวคน

- `@mediapipe/tasks-vision` `ImageSegmenter` + โมเดล selfie segmenter (เอา confidence mask ของคน)
- **ไฟล์ wasm และโมเดล .tflite ให้เสิร์ฟจากเว็บเราเอง** (`public/`) ไม่โหลดจาก CDN ของ Google ตอนรัน — เพื่อให้ไม่มีอะไรวิ่งออกนอกเว็บ และใช้ได้แม้เน็ตที่งานไม่ดี
- โหลดโมเดลแบบ lazy ตอนกด "เปิดกล้อง" ไม่ใช่ตอนเปิดหน้า
- ทำครั้งเดียวต่อรูปที่ถ่าย (ไม่ทำทุกเฟรม)

### การวางผี (หัวใจของงาน)

ลำดับการวาดลง canvas:
1. รูปที่ถ่าย (ฉากหลัง)
2. ผี (ผสมแบบแสงบนพื้นดำ) ปรับให้กลืน:
   - ขนาดอิงจากขนาดตัวคนใน mask (ผีดูอยู่ห่างออกไปนิดเดียว)
   - วางในพื้นที่ฉากหลังที่ว่างข้างตัวคน เช่น หลังไหล่/เหนือหัวเยื้องหลัง
   - ปรับโทนสี/ความสว่างตามค่าเฉลี่ยของฉากหลังบริเวณที่วาง
   - เบลอให้ใกล้ความชัดของฉากหลัง · ความเข้มจาง
3. **ตัวคน (จาก mask) วาดทับอีกชั้น** → ผีถูกบังจริง
4. เกรดทั้งภาพ: เม็ดฟิล์ม, ลดสี/อมเขียว-น้ำเงินเล็กน้อย, ขอบมืด — ใส่ทั้งคนและผีพร้อมกันเพื่อรวมเป็นภาพเดียว

แบบที่สุ่ม (อย่างน้อย):
- **หลังไหล่ซ้าย/ขวา** — ต้องมี mask คนและมีที่ว่างฝั่งนั้น
- **เหนือหัวเยื้องหลัง / ไกลออกไปในฉาก** — ผีทั้งตัวเล็ก ๆ จาง ๆ
- **โผล่มุม/ขอบจอ** — ครึ่งหน้าจากขอบภาพ ใช้ได้แม้ไม่เจอคน
- **มือแตะไหล่** — มือซีดวางบนไหล่ (ส่วนเดียวที่อยู่หน้าคน — ให้เบามาก)

ถ้าไม่เจอคน / ฉากหลังไม่มีที่ว่าง → ใช้แบบมุมจอ

### ไฟล์ผี

- สร้างด้วยเครื่องมือสร้างภาพ AI ที่มีในเครื่องมือของ Claude ตอนนี้ (Canva / Figma generate image) บนพื้นดำสนิท
- เก็บเป็นไฟล์ใน `public/ghosts/` พร้อม metadata (ประเภท: เต็มตัว/ครึ่งตัว/หน้าโผล่ขอบ/มือ, จุดยึด) ใน config แบบเดียวกับ `lib/scare/camera-config.ts`
- ห้ามใช้ไฟล์จาก `~/Downloads/Haunted pic` ตรง ๆ
- ภายหลังถ้าทีมถ่ายนักแสดงผีจริงได้ ให้เปลี่ยนแค่ไฟล์ + config

### ตัวนับ (backend)

- `POST /api/ghost-shots` ไม่ต้อง login → นับ +1 (เก็บใน `settings` หรือตารางเล็ก)
- `GET /api/admin/stats` เพิ่มฟิลด์ `ghost_shots` · แดชบอร์ดแอดมินแสดง "ถ่ายรูปผีไปแล้ว N ครั้ง"
- ไม่รับ/ไม่เก็บรูป ไม่มีข้อมูลส่วนตัว

## ข้อจำกัด

- มือถือเป็นหลัก (iOS Safari + Android Chrome) ต้องลื่นบนเครื่องกลาง ๆ
- ภาพสดต้องไม่กลับด้านผิด: กล้องหน้าแสดงแบบกระจก แต่รูปผลลัพธ์ให้ตัดสินใจให้สอดคล้อง (ดูข้อที่ปล่อยให้ผู้สร้าง)
- รักษากติกาความปลอดภัยเรื่องแฟลชเดิม (`lib/scare/shot-policy.ts`) และ reduced motion
- stack เดิม: Next.js (เวอร์ชันใหม่ — อ่าน `node_modules/next/dist/docs/` ก่อนเขียน), `motion/react`, Rust/Axum/sqlx backend, เทสต์ backend ด้วย `#[sqlx::test]`, เทสต์ frontend เป็นสคริปต์ `scripts/verify-*.cjs`
- ทำงานบน branch `feat/no-ticket-numbers` ต่อ (ยังไม่ merge)

### ฉากจบเรื่องผีชุดดำ (ตกลงแล้ว)

เรื่องผีชุดดำที่เดินเข้ามาใกล้ทุกครั้งที่กลับมาเว็บ (`lib/scare/figure-state.ts`) จบด้วย `mirrorArmed` → ชัตเตอร์ถัดไป
- **กล้องจริง:** เมื่อ `mirrorArmed` รูปถัดไปใช้**ผีชุดดำยืนอยู่ข้างหลังตัวคนพอดี** (แทนผีสุ่ม) แล้วเรียก `consumeMirror()` · ต้องสร้างไฟล์ผีชุดดำเพิ่ม 1 ตัว
- **กล้องจำลอง:** ใช้รูปกระจกแบบเดิม

### กำหนดเวลา (ตกลงแล้ว)

- **ต้องขึ้นจริงก่อนวันงาน เสาร์ 14 พ.ย. 2569** และเจ้าของงานจะดูรูปผี + รูปตัวอย่างที่ประกอบแล้วก่อนปล่อย
- ลำดับ: ระบบทั้งหมดด้วยผีชั่วคราวก่อน → สร้างผีด้วย AI → ส่งให้เจ้าของงานดู → ปรับ
- ถ้าไม่ทัน ตัดตามลำดับนี้ (ตัดท้ายก่อน): มือแตะไหล่ → ผีไกลในฉาก · ต้องมีแน่ ๆ: หลังไหล่, โผล่มุมจอ, ฉากจบผีชุดดำ
- ไม่แยก repo/เซอร์วิส: ตัวนับอยู่ใน backend เดิม (ไม่ใช้ `ISSUE_LOCK`, จำกัดต่อ IP แบบง่าย, frontend ไม่รอผล)
- ทำต่อบน branch `feat/no-ticket-numbers` แล้ว merge ทั้งหมดเข้า `main` ก่อน deploy

## ตัดสินใจโดย Claude (เจ้าของงานตรวจได้)

- กล้องจริง: **ทุกรูปมีผี** (ไม่ใช้โอกาส 50% แบบเดิม)
- กล้องจำลอง (fallback) คงพฤติกรรมเดิมทั้งหมด รวมโอกาสผี 50%
- ตัวนับ `ghost_shots` นับการกดชัตเตอร์ทั้งสองโหมด (ตรงกับที่เจ้าของงานอยากรู้ว่า "มีคนเล่นไปกี่ครั้ง")

## ปล่อยให้ผู้สร้างตัดสินใจ

- ขนาดรูปผลลัพธ์ (แนะนำ ~1080×1440) และคุณภาพ JPEG
- รูปที่ดาวน์โหลดเป็นแบบกระจก (เหมือนที่เห็นตอนถ่าย) หรือไม่กลับ — เลือกให้สอดคล้องกับภาพสด
- สูตรหา "ที่ว่างข้างตัวคน" และการวัดความชัดของฉากหลัง
- การกันสแปมตัวนับ (เช่น จำกัดต่อ IP แบบง่าย) — ตัวเลขนี้ไม่ใช่ข้อมูลสำคัญ
- ข้อความในหน้า (หัวข้อ ปุ่ม หน้ารอ) ใช้โทนเดียวกับเว็บ ไม่มีจุด/eyebrow/ตัวเอียงครึ่งหัวข้อ (ตามที่เพิ่งแก้ไป)
